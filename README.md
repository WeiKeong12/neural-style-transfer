# Neural Style Transfer

**Wei Keong Lim , Final Year Project (CM3070)**

An optimisation-based Neural Style Transfer (NST) system implemented in PyTorch, based on the approach proposed by [Gatys et al. (2016)](https://arxiv.org/abs/1508.06576).

---

## Features

- VGG16 and VGG19 feature extraction
- L-BFGS and Adam optimisation
- Content, style, and total variation loss
- Fixed and adaptive content/style weighting
- SSIM-based evaluation
- Hyperparameter grid search
- Loss-term ablation studies
- Image and video neural style transfer
- Experiment logging and visualisation

---

## Setup

### 1. Create the Conda environment

```bash
conda env create -f environment.yml
conda activate pytorch-nst
```

### 2. Install additional dependencies

Required for SSIM and image-processing functionality:

```bash
pip install scikit-image pillow
```

### 3. Install FFmpeg

FFmpeg is required for video output generated by `video-nst.py`. Make sure it's installed and available on your system `PATH`, then verify with:

```bash
ffmpeg -version
ffprobe -version
```

> **Note:** the project can use DirectML for AMD GPU acceleration when CUDA is unavailable.

## Image Neural Style Transfer

### `main-nst.py`
Performs a single image-based Neural Style Transfer experiment.

```bash
python main-nst.py ^
  --content_img_name mount-fuji.jpg ^
  --style_img_name ancient-chinese-style.jpg ^
  --model vgg16 ^
  --optimizer lbfgs ^
  --content_weight 100000 ^
  --style_weight 30000 ^
  --tv_weight 1 ^
  --num_iterations 1000
```

#### Main options
| Option                   | Available values                             |
| ------------------------ | -------------------------------------------- |
| `--model`                | `vgg16`, `vgg19`                             |
| `--optimizer`            | `lbfgs`, `adam`                              |
| `--init_method`          | `random`, `content`, `style`                 |
| `--content_weight`       | Numeric value                                |
| `--style_weight`         | Numeric value                                |
| `--tv_weight`            | Numeric value                                |
| `--num_iterations`       | Number of optimisation iterations            |
| `--adaptive_weighting`   | Enable adaptive content/style weighting      |
| `--saving_freq`          | Frequency for saving intermediate results    |
| `--skip_video`           | Skip intermediate-result video generation    |

**Example, VGG19 with Adam:**

```bash
python main-nst.py --model vgg19 --optimizer adam
```

## SSIM Evaluation, Grid Search & Ablation

### `neural_style_transfer_ssim_grid_ablation.py`
Extends the standard NST process with:

- SSIM evaluation
- Hyperparameter grid search
- Loss-term ablation studies
- Experiment result logging

A normal run automatically calculates SSIM between the generated image and the content image.

```bash
python neural_style_transfer_ssim_grid_ablation.py ^
  --content_img_name mount-fuji.jpg ^
  --style_img_name ancient-chinese-style.jpg ^
  --model vgg16 ^
  --optimizer lbfgs ^
  --num_iterations 1000
```

### Hyperparameter Grid Search

Evaluates every combination (Cartesian product) of:

- Content weight
- Style weight
- Total variation weight

```bash
python neural_style_transfer_ssim_grid_ablation.py ^
  --content_img_name mount-fuji.jpg ^
  --style_img_name ancient-chinese-style.jpg ^
  --model vgg16 ^
  --optimizer lbfgs ^
  --grid_search ^
  --grid_content_weights 50000,75000,100000,150000,200000 ^
  --grid_style_weights 30000 ^
  --grid_tv_weights 1 ^
  --grid_iterations 1000
```

> **Example:** 5 content weights × 1 style weight × 1 TV weight = 5 experiments
> **Default grid:** 2 × 2 × 2 = 8 experiments

Results are recorded in the experiment's `data/data-visual/` directory.

### Ablation Study

```bash
python neural_style_transfer_ssim_grid_ablation.py ^
  --content_img_name mount-fuji.jpg ^
  --style_img_name ancient-chinese-style.jpg ^
  --model vgg16 ^
  --optimizer lbfgs ^
  --ablation_study ^
  --grid_iterations 1000
```

Each variant is run automatically and evaluated using the same NST pipeline, including SSIM evaluation.

## Video Neural Style Transfer
### `video-nst.py`

Performs frame-by-frame Neural Style Transfer on an input video.
The first frame is stylised independently. Subsequent frames use a blended initialisation primarily the current video frame, plus a smaller contribution from the previous stylised frame to maintain temporal consistency while following the video's movement.

```bash
python video-nst.py
```

The script prompts for the input content video and style image. Key settings can be configured directly in `video-nst.py`:

```text
FIRST_FRAME_ITERATIONS
LATER_FRAME_ITERATIONS
CONTENT_WEIGHT
STYLE_WEIGHT
TV_WEIGHT
FRAME_WIDTH
STYLE_IMAGE_SIZE
GHOST_FRAME_BLEND
LBFGS_HISTORY_SIZE
```

#### Resume support
Processed frames are checkpointed under `data/output-videos/_frames/`. If processing is interrupted, re-running the script resumes from the existing checkpoints.

#### FFmpeg video encoding
The generated video is encoded via FFmpeg into an H.264-compatible MP4 for broad compatibility (including VS Code's built-in video preview).

#### Quick testing
For a short test run:

```python
MAX_FRAMES = 10
```

Then, to process the full video:

```python
MAX_FRAMES = None
```

## Project Summary

This project investigates optimisation-based Neural Style Transfer using different CNN feature extractors, optimisation algorithms, loss-weight configurations, and initialisation strategies.

The experimental framework enables evaluation of these choices through generated images, optimisation losses, SSIM measurements, grid-search experiments, ablation studies, and video stylisation results.
